# Onvoltooid Tegenwoordige Tijd (OTT)

### Enkelvoud
Is het <span class="ow">onderwerp</span> enkelvoud, dan gebruik je de <span class="ikvorm">ik-vorm</span>.
- Als de <span class="ikvorm">ik-vorm</span> *niet* eindigt op een **d**: Schrijf wat je hoort.
- Als de <span class="ikvorm">ik-vorm</span> eindigt op een **d**:
  - Bij <span class="ow">ik</span> ervoor of <span class="ow">jij</span> of <span class="ow">je</span> erachter gebruik je de <span class="ikvorm">ik-vorm</span>.
  - Anders krijgt de <span class="ikvorm">ik-vorm</span> een **t**. Dit wordt de dt-regel genoemd.

**Check:** Vervang het werkwoord door een werkwoord dat niet op een **d** eindigt. Hoor of er een **t** achter de **d** van de <span class="ikvorm">ik-vorm</span> moet.

### Voorbeelden

- <span class="ow">Ik</span> <span class="ikvorm">voer</span> de kippen.
- <span class="ow">De kip</span> <span class="ikvorm">pik</span>**t** het konijn.
- <span class="ikvorm">Knip</span> <span class="ow">jij</span> de vleugel van de kip?
- <span class="ikvorm">Knip</span>**t** <span class="ow">jouw moeder</span> de kip?
- <span class="ow">Ik</span> <span class="ikvorm">braad</span> de kip.
- <span class="ow">Mama</span> <span class="ikvorm">braad</span>**t** de kip.
- <span class="ikvorm">Braad</span> <span class="ow">jij</span> de kip?
- <span class="ikvorm">Braad</span>**t** <span class="ow">jouw moeder</span> de kip?

### Meervoud

Is het <span class="ow">onderwerp</span> meervoud, dan gebruik je de <span class="wijvorm">wij-vorm</span>: het hele werkwoord. Schrijf wat je hoort.


### Voorbeelden

- <span class="ow">De kippen</span> <span class="wijvorm">haten</span> Stampertje.
- <span class="ow">De kippen</span> <span class="wijvorm">braden</span> Stampertje.
- <span class="ow">De kippen</span> <span class="wijvorm">knippen</span> Stampertjes staart af.

# Onvoltooid Verleden Tijd (OVT)

### Zwakke (klankvaste) werkwoorden
- Is het <span class="ow">onderwerp</span> enkelvoud? Dan gebruik je de <span class="ikvorm">ik-vorm</span> + **te** of **de**.
- Is het <span class="ow">onderwerp</span> meervoud? Dan gebruik je de <span class="ikvorm">ik-vorm</span> + **ten** of **den**.

**Tips:**
1. Luister naar het meervoud om te horen of het **te** of **de** is.
2. Check het "kofschip" of het **te** of **de** is. Zie [VTT](#voltooid-tegenwoordige-tijd-vtt).

### Voorbeelden

- <span class="ow">De kip</span> <span class="ikvorm">pik</span>**te** het konijn.
- <span class="ow">Ik</span> <span class="ikvorm">voer</span>**de** de kippen.
- <span class="ow">Mama</span> <span class="ikvorm">braad</span>**de** de kip.
- <span class="ow">Beta</span> <span class="ikvorm">haat</span>**te** Stampertje.
- <span class="ow">De kippen</span> <span class="ikvorm">pik</span>**ten** het konijn.
- <span class="ow">Wij</span> <span class="ikvorm">voer</span>**den** de kippen.
- <span class="ow">Mama en papa</span> <span class="ikvorm">braad</span>**den** de kip.
- <span class="ow">Beta en Boomer</span> <span class="ikvorm">haat</span>**ten** Stampertje.

### Sterke (klankveranderende) werkwoorden
Schrijf wat je hoort.

### Voorbeelden

- <span class="ow">Ik</span> <span class="ww">ving</span> de kippen.
- <span class="ow">De kip</span> <span class="ww">sprong</span> op de bank.
- <span class="ow">De kippen</span> <span class="ww">sloegen</span> het konijn.
- <span class="ow">De kippen</span> <span class="ww">bewogen</span> bijna niet.
- <span class="ow">De kippen</span> <span class="ww">schrokken</span> van Stampertje.

# Voltooid Tegenwoordige Tijd (VTT)

Het <span class="ww">voltooid deelwoord</span> laat zien dat iets afgerond is. Het voltooid deelwoord staat nooit alleen. Er staat altijd een vorm van <span class="h ww">hebben</span>, <span class="h ww">zijn</span> of <span class="h ww">worden</span> bij in de zin als <span class="h ww">hulpwerkwoord</span>.

### Zwakke (klankvaste) werkwoorden
Voor zwakke werkwoorden geldt de "kofschip/exkofschaap"-regel. Kijk naar de laatste letter van de <span class="wijvorm">wij-vorm</span> zonder *-en*:
- Staat die letter in "kofschip"? Dan eindigt het voltooid deelwoord op een **t**.
- Staat die letter *niet* in "kofschip"? Dan eindigt het voltooid deelwoord op een **d**.

**Check:** Luister naar de verleden tijd om te horen of het een **d** of een **t** moet zijn.

### Voorbeelden

- <span class="ow">De kip</span> <span class="h ww">heeft</span> het konijn <span class="ww">gepik</span>**t**.
- <span class="ow">Ik</span> <span class="h ww">heb</span> de kippen <span class="ww">gevoer</span>**d**.
- <span class="ow">Mama</span> <span class="h ww">heeft</span> de kip <span class="ww">gebraad</span>.
- <span class="ow">Beta</span> <span class="h ww">heeft</span> Stampertje <span class="ww">gehaat</span>.
- <span class="ow">De kippen</span> <span class="h ww">hebben</span> de konijnen <span class="ww">gepik</span>**t**.
- <span class="ow">Stampertje</span> <span class="h ww">is</span> <span class="ww">gehaat</span> door de kippen.
- <span class="ow">Wij</span> <span class="h ww">hebben</span> de kippen <span class="ww">gevoer</span>**d**.

### Sterke (klankveranderende) werkwoorden
Het voltooid deelwoord eindigt op **en**. Schrijf wat je hoort.

### Voorbeelden

- <span class="ow">Ik</span> <span class="h ww">heb</span> de kippen <span class="ww">gevang</span>**en**.
- <span class="ow">De kippen</span> <span class="h ww">zijn</span> op de bank <span class="ww">gesprong</span>**en**.
- <span class="ow">De kippen</span> <span class="h ww">worden</span> door het konijn <span class="ww">geslag</span>**en**.
- <span class="ow">De kippen</span> <span class="h ww">zijn</span> bijna niet <span class="ww">bewog</span>**en**.
- <span class="ow">De kippen</span> <span class="h ww">zijn</span> <span class="ww">geschrokk</span>**en** van Stampertje.

---

# Voltooid Verleden Tijd (VVT)

Ook hier is het <span class="ww">voltooid deelwoord</span> afgerond. Het <span class="h ww">hulpwerkwoord</span> staat nu in de verleden tijd: <span class="h ww">had</span>, <span class="h ww">hadden</span>, <span class="h ww">was</span> of <span class="h ww">waren</span>. Het voltooid deelwoord schrijf je net zoals bij de VTT.

### Voorbeelden

- <span class="ow">De kip</span> <span class="h ww">had</span> het konijn <span class="ww">gepik</span>**t**.
- <span class="ow">Stampertje</span> <span class="h ww">was</span> <span class="ww">gehaat</span> door de kippen.
- <span class="ow">Mama</span> <span class="h ww">had</span> de kip <span class="ww">gebraad</span>.
- <span class="ow">Wij</span> <span class="h ww">hadden</span> de kippen <span class="ww">gevoer</span>**d**.

# Deelwoorden

Een <span class="ww">deelwoord</span> is een vorm van een werkwoord. Er zijn twee soorten: het voltooid deelwoord en het onvoltooid deelwoord.

### Voltooid deelwoord
Het <span class="ww">voltooid deelwoord</span> laat zien dat iets afgerond is. Zie [VTT](#voltooid-tegenwoordige-tijd-vtt).

### Onvoltooid deelwoord
Het <span class="ww">onvoltooid deelwoord</span> laat zien dat iets aan de gang is. Je maakt het met de <span class="wijvorm">wij-vorm</span> + **d**.

### Voorbeelden

- De kip zat <span class="ww">kakelend</span> achter Stampertje aan.
- Tak en Toe gingen <span class="ww">rennend</span> naar hun nest.

### Deelwoord als bijvoeglijk naamwoord
Een deelwoord kun je ook als <span class="bijvbep">bijvoeglijk naamwoord</span> gebruiken.

| | Lange vorm<br> | Korte vorm |
| --- | --- | --- |
| | Deelwoord met een **e**. | Deelwoord zonder **e**. |
| **Voltooid deelwoord** | De <span class="ww">gepikt</span>**e** kip.<br>De <span class="ww">gevoerd</span>**e** kip.<br>De <span class="ww">gebrad</span>**e** kip.<br>Het <span class="ww">gehat</span>**e** konijn. | Een <span class="ww">gevoerd</span> konijn.<br>Een <span class="ww">gepikt</span> konijn.<br>Een <span class="ww">gehaat</span> konijn.<br>Een <span class="ww">gebraad</span> konijn. |
| **Onvoltooid deelwoord** | De <span class="ww">kakelend</span>**e** kip.<br>De <span class="ww">rennend</span>**e** kippen. | Een <span class="ww">hatend</span> konijn.<br>Een <span class="ww">rennend</span> konijn. |
