| | Tegenwoordig | Verleden |
| --- | --- | --- |

# Onvoltooid Tegenwoordige Tijd (OTT)

### Enkelvoud
Is het <span class="ow">onderwerp</span> enkelvoud, dan gebruik je de <span class="ikvorm">ik-vorm</span>.
- Als de <span class="ikvorm">ik-vorm</span> *niet* eindigt op een **d**: Schrijf wat je hoort.
- Als de <span class="ikvorm">ik-vorm</span> eindigt op een **d**:
  - Bij <span class="ow">ik</span> ervoor of <span class="ow">jij</span> of <span class="ow">je</span> erachter gebruik je de <span class="ikvorm">ik-vorm</span>.
  - Anders krijgt de <span class="ikvorm">ik-vorm</span> een **t**. Dit wordt de dt-regel genoemd.

**Tip:** Vervang het werkwoord door een werkwoord dat niet op een **d** eindigt. Hoor of er een **t** achter de **d** van de <span class="ikvorm">ik-vorm</span> moet.

### Voorbeelden

- <span class="ow">Ik</span> <span class="ikvorm">voer</span> de kippen.
- <span class="ow">De kip</span> <span class="ikvorm">pik</span>**t** het konijn.
- <span class="ikvorm">Knip</span> <span class="ow">jij</span> de vleugel van de kip?
- <span class="ikvorm">Knip</span>**t** <span class="ow">jouw moeder</span> de kip?
- <span class="ow">Ik</span> <span class="ikvorm">braad</span> de kip.
- <span class="ow">Mama</span> <span class="ikvorm">braad</span>**t** de kip.
- <span class="ikvorm">Braad</span> <span class="ow">jij</span> de kip?
- <span class="ikvorm">Braad</span>**t** <span class="ow">jouw moeder</span> de kip?

### Meervoud

Is het <span class="ow">onderwerp</span> meervoud, dan gebruik je de <span class="wijvorm">wij-vorm</span>: het hele werkwoord. Schrijf wat je hoort.


### Voorbeelden

- <span class="ow">De kippen</span> <span class="wijvorm">haten</span> Stampertje.
- <span class="ow">De kippen</span> <span class="wijvorm">braden</span> Stampertje.
- <span class="ow">De kippen</span> <span class="wijvorm">knippen</span> Stampertjes staart af.

# Onvoltooid Verleden Tijd (OVT)

### Zwakke (klankvaste) werkwoorden
- Is het <span class="ow">onderwerp</span> enkelvoud? Dan gebruik je de <span class="ikvorm">ik-vorm</span> + **te** of **de**.
- Is het <span class="ow">onderwerp</span> meervoud? Dan gebruik je de <span class="ikvorm">ik-vorm</span> + **ten** of **den**.

**Tips:**
1. Luister naar het meervoud om te horen of het **te** of **de** is.
2. Check het "kofschip" of het **te** of **de** is. Zie voltooid deelwoord.

### Voorbeelden

- <span class="ow">De kip</span> <span class="ikvorm">pik</span>**te** het konijn.
- <span class="ow">Ik</span> <span class="ikvorm">voer</span>**de** de kippen.
- <span class="ow">Mama</span> <span class="ikvorm">braad</span>**de** de kip.
- <span class="ow">Beta</span> <span class="ikvorm">haat</span>**te** Stampertje.
- <span class="ow">De kippen</span> <span class="ikvorm">pik</span>**ten** het konijn.
- <span class="ow">Wij</span> <span class="ikvorm">voer</span>**den** de kippen.
- <span class="ow">Mama en papa</span> <span class="ikvorm">braad</span>**den** de kip.
- <span class="ow">Beta en Boomer</span> <span class="ikvorm">haat</span>**ten** Stampertje.

### Sterke (klankveranderende) werkwoorden
Schrijf wat je hoort.

### Voorbeelden

- <span class="ow">Ik</span> <span class="ww">ving</span> de kippen.
- <span class="ow">De kip</span> <span class="ww">sprong</span> op de bank.
- <span class="ow">De kippen</span> <span class="ww">sloegen</span> het konijn.
- <span class="ow">De kippen</span> <span class="ww">bewogen</span> bijna niet.
- <span class="ow">De kippen</span> <span class="ww">schrokken</span> van Stampertje.
