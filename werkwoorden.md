# Onvoltooid Tegenwoordige Tijd (OTT)

### Enkelvoud
Is het <span class="ow">onderwerp</span> enkelvoud, dan gebruik je de <span class="ikvorm">ik-vorm</span>.
- Als de <span class="ikvorm">ik-vorm</span> *niet* eindigt op een **d**: Schrijf wat je hoort.
- Als de <span class="ikvorm">ik-vorm</span> eindigt op een **d**:
  - Bij <span class="ow">ik</span> ervoor of <span class="ow">jij</span> of <span class="ow">je</span> erachter gebruik je de <span class="ikvorm">ik-vorm</span>.
  - Anders krijgt de <span class="ikvorm">ik-vorm</span> een **t**.

**Check:** Vervang het werkwoord door een werkwoord dat niet op een **d** eindigt. Hoor of er een **t** achter de **d** van de <span class="ikvorm">ik-vorm</span> moet.

### Voorbeelden

- <span class="ow">Ik</span> <span class="ikvorm">voer</span> de kippen.
- <span class="ow">De kip</span> <span class="ikvorm">pik</span>**t** het konijn.
- <span class="ikvorm">Knip</span> <span class="ow">jij</span> de vleugel van de kip?
- <span class="ikvorm">Knip</span>**t** <span class="ow">jouw moeder</span> de kip?
- <span class="ow">Ik</span> <span class="ikvorm">braad</span> de kip.
- <span class="ow">Mama</span> <span class="ikvorm">braad</span>**t** de kip.
- <span class="ikvorm">Braad</span> <span class="ow">jij</span> de kip?
- <span class="ikvorm">Braad</span>**t** <span class="ow">jouw moeder</span> de kip?

### Meervoud

Is het <span class="ow">onderwerp</span> meervoud, dan gebruik je de <span class="wijvorm">wij-vorm</span>: het hele werkwoord. Schrijf wat je hoort.


### Voorbeelden

- <span class="ow">De kippen</span> <span class="wijvorm">haten</span> Stampertje.
- <span class="ow">De kippen</span> <span class="wijvorm">braden</span> Stampertje.
- <span class="ow">De kippen</span> <span class="wijvorm">knippen</span> Stampertjes staart af.
