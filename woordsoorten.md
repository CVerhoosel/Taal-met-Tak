# Zelfstandig naamwoord (zn)
Een <span class="zn">zelfstandig naamwoord (zn)</span> is een woord voor een mens, dier, ding, etc. Een <span class="zn">eigennaam (zn-e)</span> is ook een zelfstandig naamwoord.

### Voorbeelden
- <span class="zn">kip</span>
- <span class="zn">eten</span>
- <span class="zn">Tak</span>

# Lidwoord (lw)
Ieder <span class="zn">zelfstandig naamwoord (zn)</span> heeft een <span class="lw">lidwoord</span>:
- <span class="lw">Bepaald (blw)</span>: <span class="lw">de</span>, <span class="lw">het</span>
- <span class="lw">Onbepaald (old)</span>: <span class="lw">een</span>

### Voorbeelden
- <span class="lw">de</span> <span class="zn">kip</span>
- <span class="lw">het</span> <span class="zn">eten</span>
- <span class="lw">een</span> <span class="zn">konijn</span>

# Bijvoeglijk naamwoord (bn)
Een <span class="bn">bijvoeglijk naamwoord (bn)</span> zegt iets over een <span class="zn">zelfstandig naamwoord (zn)</span>. Een <span class="bn">stoffelijk bijvoeglijk naamwoord (st.bn)</span> zegt waarvan iets is gemaakt.

### Voorbeelden
- <span class="lw">de</span> <span class="bn">geniale</span> <span class="zn">kip</span>
- <span class="lw">het</span> <span class="bn">lekkere</span> <span class="zn">eten</span>
- <span class="lw">een</span> <span class="bn">irritant</span> <span class="zn">konijn</span>

# Werkwoorden
Een <span class="z ww">zelfstandig werkwoord (zww)</span> zegt wat iets of iemand doet. Het heeft een duidelijke betekenis. <span class="h ww">hulpwerkwoorden (hww)</span> komen voor in zinnen met meerdere werkwoorden. Ze helpen om een gezegde te maken.

### Voorbeelden
- Tak <span class="h ww">heeft</span> al drie keer naar het hok <span class="z ww">gerend</span>.
- De kip <span class="h ww">kan</span> heel hoog <span class="z ww">springen</span>.
- Stampertje <span class="h ww">wordt</span> steeds door Tak <span class="z ww">geplaagd</span>.
- Het konijn <span class="h ww">zal</span> straks weer voer <span class="z ww">pakken</span>.
- Tak <span class="h ww">is</span> net uit haar hok <span class="z ww">gekomen</span>.
