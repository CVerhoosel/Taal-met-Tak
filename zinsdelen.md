# Persoonsvorm (pv)

De <span class="pv">persoonsvorm</span> is het werkwoord dat laat zien wie of wat de handeling uitvoert en in welke tijd de zin staat.

### Hoe vind ik de persoonsvorm?
Maak van de zin een **ja/nee-vraag**. Het werkwoord dat dan vooraan komt is de <span class="pv">persoonsvorm</span>.

### Voorbeelden
- Tak <span class="pv">loopt</span> door de tuin.
- Het konijn <span class="pv">slaapt</span> in zijn hok.
- Waarom <span class="pv">blokkeert</span> Stampertje mijn pad?

---

# Zinsdelen
Een \| zinsdeel \| kan één woord zijn, maar ook een groep woorden.

### Hoe vind ik de zinsdelen?
Probeer welke woorden je samen voor de <span class="pv">persoonsvorm</span> kan zetten. Die woorden vormen samen een \| zinsdeel \|.

### Voorbeelden
- \| Tak \| <span class="pv">loopt</span> \| door de tuin \|.
- \| Het konijn \| <span class="pv">slaapt</span>  \| in zijn hok \|.
- \| Waarom \| <span class="pv">blokkeert</span> \| Stampertje \| mijn pad \|?

---

# Onderwerp (ow)

Het <span class="ow">onderwerp</span> is degene of datgene waar de zin over gaat. Het doet iets of er wordt iets over gezegd.

### Hoe vind ik het onderwerp?
Stel de vraag **Wie/wat +** <span class="pv">persoonsvorm</span>**?** Het antwoord is het <span class="ow">onderwerp</span>.

### Voobeelden
- \| <span class="ow">Tak</span> \| <span class="pv">loopt</span> \| door de tuin \|.
- \| <span class="ow">Het konijn</span> \| <span class="pv">slaapt</span>  \| in zijn hok \|.
- \| Waarom \| <span class="pv">blokkeert</span> \| <span class="ow">Stampertje</span> \| mijn pad \|?

---

# Werkwoordelijk gezegde (wg) 
Het <span class="wg">werkwoordelijk gezegde</span> zegt wat het onderwerp doet of overkomt.

### Hoe vind ik het werkwoordelijk gezegde?
Het <span class="wg">werkwoordelijk gezegde</span> bestaat uit de persoonsvorm plus alle andere werkwoorden. Delen van een scheidbaar werkwoord horen er ook bij.

### Voorbeelden
- \| Tak \| <span class="wg">wordt</span> \| door Stampertje \| <span class="wg">gepest</span> \|.
- \| Tak \| <span class="wg">is</span> \| in haar hok \| <span class="wg">opgesloten</span> \|.
- \| Tak \| <span class="wg">wordt</span> \| elke dag <span class="wg">gevoerd</span> \|.
- \| Tak \| <span class="wg">jaagt</span> \| de konijnen \| <span class="wg">op</span> \|.

---

# Lijdend voorwerp (lv)
Het <span class="lv">lijdend voorwerp</span> geeft aan wie of wat iets overkomt.

### Hoe vind ik het lijdend voorwerp?
Stel de vraag **Wie/wat +** <span class="wg">werkwoordelijk gezegde</span> + <span class="ow">onderwerp</span>**?** Het antwoord is het <span class="lv">lijdend voorwerp</span>.

### Voorbeelden
- \| <span class="ow">Stampertje</span> \| <span class="wg">pest</span> \| <span class="lv">Tak</span> \|.
- \| <span class="ow">Tak</span> \| <span class="wg">jaagt</span> \| <span class="lv">de konijnen</span> \| <span class="wg">op</span> \|.
- \| <span class="ow">Tak</span> \| <span class="wg">eet</span> \| <span class="lv">de mais</span> \|.
- \| <span class="ow">Mijn moeder</span> \| <span class="wg">voert</span> \| <span class="lv">Tak</span> \| elke ochtend \|.

---

# Meewerkend voorwerp (mv)
Het <span class="mv">meewerkend voorwerp</span> geeft aan voor wie iets bestemd is.

### Hoe vind ik het meewerkend voorwerp?
Stel de vraag **Aan wie +** <span class="wg">werkwoordelijk gezegde</span> + <span class="ow">onderwerp</span> + <span class="lv">lijdend voorwerp</span>**?** Het antwoord is het <span class="mv">meewerkend voorwerp</span>.

### Voorbeelden
- \| <span class="ow">Tak</span> \| <span class="wg">geeft</span> \| <span class="mv">de konijnen</span> \| <span class="lv">een preek</span> \|.
- \| <span class="ow">Stampertje</span> \| <span class="wg">geeft</span> \| <span class="mv">Tak</span> \| <span class="lv">een duw</span> \|.
- \| <span class="ow">Stampertje</span> \| <span class="wg">vertelt</span> \| <span class="mv">Tak</span> \| <span class="lv">een verhaal</span> \|.
- \| <span class="ow">Mijn moeder</span> \| <span class="wg">heeft</span> \| <span class="mv">Tak</span> \| <span class="lv">graan</span> \| <span class="wg">gegeven</span> \|.

---

# Bijwoordelijke bepaling (bwb)
Een <span class="bwb">bijwoordelijke bepaling</span> geeft een *plaats*, *tijd* of *reden* aan.

### Hoe vind ik bijwoordelijke bepaling?
Zoek het <span class="ow">onderwerp</span>, <span class="wg">werkwoordelijk gezegde</span>, <span class="lv">lijdend voorwerp</span> en <span class="mv">meewerkend voorwerp</span>. Zoek of er zinsdelen zijn die antwoord geven op vragen zoals **Waar?**, **Wanneer?** en **Hoe?** Dit zijn (meestal) <span class="bwb">bijwoordelijke bepalingen</span>. De vraagwoorden zelf zijn ook <span class="bwb">bijwoordelijke bepalingen</span>.

### Voorbeelden
- \| <span class="ow">Tak</span> \| <span class="wg">zoekt</span> \| <span class="lv">eieren</span> \| <span class="bwb">in het kippenhok</span> \|.
- \| <span class="ow">Tak</span> \| <span class="wg">scharrelt</span> \| <span class="bwb">door de tuin</span> \|.
- \| <span class="ow">Tak</span> \| <span class="wg">legt</span> \| <span class="bwb">elke ochtend</span> \| <span class="lv">een ei</span> \|.
- \| <span class="ow">Mijn moeder</span> \| <span class="wg">geeft</span> \| <span class="mv">Tak</span> \| <span class="bwb">'s avonds</span> \| <span class="lv">graan</span> \|.
- \| <span class="ow">Tak</span> \| <span class="wg">verstopt zich</span> \| <span class="bwb">vanwege de regen</span> \|.
- \| <span class="ow">Tak</span> \| <span class="wg">piept</span> \| <span class="bwb">luidkeels</span> \| <span class="bwb">uit angst</span> \|.
- \| <span class="bwb">Waarom</span> \| <span class="wg">blokkeert</span> \| <span class="ow">Stampertje</span> \| <span class="lv">mijn pad</span> \|?

# Zinsdeelstukken
De **kern** is het belangrijkste woord van een \| zinsdeel \|. Zinsdeelstukken geven extra informatie over die **kern**. 

### Hoe vind ik de zinsdeelstukken?
1. Bepaal de woordsoort van de **kern**.
2. De woorden die extra informatie geven zijn dan:
    - <span class="bijvbep">Bijvoeglijke bepaling (bijv.bep)</span>: Wanneer de **kern** een zelfstandig naamwoord of voornaamwoord is. Lidwoorden, voornaamwoorden, telwoorden en voorzetsels aan het begin van een \| zinsdeel \| zijn geen bijvoeglijke bepalingen.
    - <span class="obwb">Ondergeschikte bijwoordelijke bepaling (obwb)</span>: Wanneer de **kern** geen zelfstandig naamwoord of voornaamwoord is (bijv. een werkwoord, bijvoeglijk naamwoord of bijwoord).
    - <span class="bijst">Bijstelling (bijst)</span>: Staat vaak tussen komma's of een komma en een punt. Een bijstelling duidt dezelfde persoon of zaak aan als het woord ervoor.
    
### Voorbeelden

- \| Het <span class="bijvbep">irritante</span> **konijn** \| loopt \| naar zijn hok \|.
    - <span class="bijvbep">bijv.bep=irritante</span> → **konijn**

- \| De **kippen** \| zijn \| altijd \| <span class="obwb">heel</span> **geobsedeerd** \| door eten \|.
    - <span class="obwb">obwb=heel</span> → **geobsedeerd**

- \| **Stampertje**, <span class="bijst">dat knaagdier</span> \| <span class="wg">duwt</span> \| de kippen \|.
    - <span class="bijst">bijst=dat knaagdier</span> → **Stampertje**

# Samengestelde zin
Een zin met maar één <span class="pv">persoonsvorm</span> heet een <span class="zin">enkelvoudige zin</span>. Een zin met meerdere <span class="pv">persoonsvormen</span> heet een <span class="zin">samengestelde zin</span>.

Een <span class="zin">samengestelde zin</span> bestaat uit:
- Twee of meer samengevoegde <span class="zin hoofd">hoofdzinnen</span>
- Eén of meer <span class="zin hoofd">hoofdzinnen</span> en één of meer <span class="zin bij">bijzinnen</span>

### Hoe vind je een hoofdzin of bijzin?
- In een <span class="zin hoofd">hoofdzin</span> staan <span class="ow">onderwerp</span> en <span class="pv">persoonsvorm</span> bij elkaar en meestal vooraan in de zin. In een <span class="zin bij">bijzin</span> is dit niet zo.
- Twee <span class="zin hoofd">hoofdzinnen</span> of twee <span class="zin bij">bijzinnen</span> zijn meestal **nevenschikkend** verbonden. Een <span class="zin hoofd">hoofdzin</span> en een <span class="zin bij">bijzin</span> zijn doorgaans **onderschikkend** verbonden.

### Voorbeelden
- <span class="zin hoofd"><span class="ow">Tak</span> <span class="wg"><span class="pv">scharrelt</span></span> door de tuin</span> en <span class="zin hoofd"><span class="ow">de konijnen</span> <span class="wg"><span class="pv">lopen</span></span> weg</span>. → **Nevenschikkend**
- <span class="zin hoofd"><span class="ow">Stampertje</span> <span class="wg"><span class="pv">duwt</span></span> Tak</span>, maar <span class="zin hoofd"><span class="ow">Tak</span> <span class="wg"><span class="pv">blijft</span></span> staan</span>. → **Nevenschikkend**
- <span class="zin hoofd"><span class="ow">Tak</span> <span class="wg"><span class="pv">kakelt</span></span> luid,</span> omdat <span class="zin bij"><span class="ow">Stampertje</span> haar <span class="wg"><span class="pv">pest</span></span></span>. → **Onderschikkend**
- <span class="zin bij">Toen <span class="ow">mijn moeder</span> <span class="wg"><span class="pv">kwam</span> zoeken</span></span>, <span class="zin hoofd"><span class="wg"><span class="pv">verstopte</span></span> <span class="ow">Tak</span> zich</span>. → **Onderschikkend**
- <span class="zin hoofd"><span class="ow">De konijnen</span> <span class="wg"><span class="pv">lopen</span></span> weg</span> als <span class="zin bij"><span class="ow">Tak</span> <span class="wg"><span class="pv">komt</span></span></span>. → **Onderschikkend**

# Zinsdeelzinnen
Als een <span class="zin">samengestelde zin</span> bestaat uit een <span class="zin hoofd">hoofdzin</span> en een <span class="zin bij">bijzin</span>, dan noem je de <span class="zin bij">bijzin</span> een \| <span class="zin"> zinsdeelzin </span> \|. Het is namelijk een \| zinsdeel \| binnen de hoofdzin.

De meest voorkomende \| <span class="zin"> zinsdeelzinnen </span> \| zijn:
- <span class="ow zin"> onderwerpszin (ow-zin) </span>
- <span class="lv zin"> lijdendvoorwerpszin (lv-zin) </span>
- <span class="mv zin"> meewerkendvoorwerpszin (mv-zin) </span>
- <span class="bwb zin"> bijwoordelijkebepalingszin (bwb-zin) </span>

### Hoe bepaal ik het soort zinsdeelzin?
Bepaal de hoofd- en bijzin(nen). Vervang (iedere) bijzin door een woord (of een paar woorden). Bepaal het \| zinsdeel \| van dit woord (of deze groep woorden). Dit bepaalt dan ook het soort \| <span class="zin"> zinsdeelzin </span> \|.

### Voorbeelden van zinsdeelzinnen
- <span class="zin hoofd">Het blijkt</span> dat <span class="zin bij ow zin">Tak stiekem op het dak klimt</span>.
    - <span class="zin hoofd">Het blijkt</span> <span class="ow">dat</span>.  → <span class="ow">onderwerp</span>
- <span class="zin hoofd">Stampertje weet</span> dat <span class="zin bij lv zin">Tak achter het hok schuilt</span>.
    - <span class="zin hoofd">Stampertje weet</span> <span class="lv">het</span>. → <span class="lv">lijdend voorwerp</span>
- <span class="zin hoofd">Mijn moeder vertelt</span> aan wie <span class="zin bij mv zin">Tak haar eitjes geeft</span>.
    - <span class="zin hoofd">Mijn moeder vertelt</span> <span class="mv">aan Tak</span> → <span class="mv">meewerkend voorwerp</span>
- <span class="zin hoofd">Tak kakelt</span> omdat <span class="zin bij bwb zin">Stampertje haar opjaagt</span>.
    - <span class="zin hoofd">Tak kakelt</span> <span class="bwb">door dat gejaag</span>. → <span class="bwb">bijwoordelijke bepaling</span>

# Bijvoeglijke bijzin
Als de **kern** van een \| zinsdeel \| een zelfstandig naamwoord of voornaamwoord is, dan wordt een zinnetje dat iets zegt over de **kern** een <span class="bijvbij zin"> bijvoeglijke bijzin (bijv.bijzin)</span> genoemd.

### Hoe vind ik een bijvoeglijke bijzin?
Een <span class="bijvbij zin"> bijvoeglijke bijzin</span> werkt precies zoals een <span class="bijvbep">bijvoeglijke bepaling</span>,  maar dan in de vorm van een zin, dus met een <span class="pv">persoonsvorm</span>. Die zin geeft extra informatie over een zelfstandig naamwoord of voornaamwoord.

### Voorbeelden
- \| De <span class="kern">kip</span> <span class="bij bijvbij zin">die altijd te laat is</span> \| rent \| naar het hok \|.
- \| Tak \| pikt \| het <span class="kern">graan</span> <span class="bijvbij zin">dat Stampertje net liet vallen</span> \| op \|.
- \| De <span class="kern">emmer</span> <span class="bijvbij zin">waarin Tak had gepoept</span> \| staat \| nog \| bij het hek \|.
