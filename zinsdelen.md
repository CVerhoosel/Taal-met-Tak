# Persoonsvorm (pv)

De <span class="pv">persoonsvorm</span> is het werkwoord dat laat zien wie of wat de handeling uitvoert en in welke tijd de zin staat.

### Hoe vind ik de persoonsvorm?
Maak van de zin een **ja/nee-vraag**. Het werkwoord dat dan vooraan komt is de <span class="pv">persoonsvorm</span>.

### Voorbeelden
- Tak <span class="pv">loopt</span> door de tuin.
- Het konijn <span class="pv">slaapt</span> in zijn hok.
- Waarom <span class="pv">blokkeert</span> Stampertje mijn pad?

# Zinsdelen
Een \| zinsdeel \| kan één woord zijn, maar ook een groep woorden.

## Hoe vind ik de zinsdelen?
Probeer welke woorden je samen voor de <span class="pv">persoonsvorm</span> kan zetten. Die woorden vormen samen een \| zinsdeel \|.

## Voorbeelden
- \| Tak \| <span class="pv">loopt</span> \| door de tuin \|.
- \| Het konijn \| <span class="pv">slaapt</span>  \| in zijn hok \|.
- \| Waarom \| <span class="pv">blokkeert</span> \| Stampertje \| mijn pad \|?

## Onderwerp (ow)

Het <span class="ow">onderwerp</span> is degene of datgene waar de zin over gaat. Het doet iets of er wordt iets over gezegd.

## Hoe vind ik het onderwerp?
Stel de vraag **Wie/wat + persoonsvorm?** Het antwoord is het <span class="ow">onderwerp</span>.

## Voobeelden
- \| <span class="ow">Tak</span> \| <span class="pv">loopt</span> \| door de tuin \|.
- \| <span class="ow">Het konijn</span> \| <span class="pv">slaapt</span>  \| in zijn hok \|.
- \| Waarom \| <span class="pv">blokkeert</span> \| <span class="ow">Stampertje</span> \| mijn pad \|?

---

# Werkwoordelijk gezegde (wg) 
Het <span class="wg">werkwoordelijk gezegde</span> zegt wat het onderwerp doet of overkomt.

## Hoe vind ik het werkwoordelijk gezegde?
Het <span class="wg">werkwoordelijk gezegde</span> bestaat uit de persoonsvorm plus alle andere werkwoorden. Delen van een scheidbaar werkwoord horen er ook bij.

## Voorbeelden
- \| Tak \| <span class="wg">wordt</span> \| door Stampertje \| <span class="wg">gepest</span> \|.
- \| Tak \| <span class="wg">is</span> \| in haar hok \| <span class="wg">opgesloten</span> \|.
- \| Tak \| <span class="wg">wordt</span> \| elke dag <span class="wg">gevoerd</span> \|.
- \| Tak \| <span class="wg">jaagt</span> \| de konijnen \| <span class="wg">op</span> \|.

---

# Lijdend voorwerp (lv)
Het <span class="lv">lijdend voorwerp</span> geeft aan wie of wat iets overkomt.

## Hoe vind ik het lijdend voorwerp?
Stel de vraag **Wie/wat +** <span class="wg">werkwoordelijk gezegde</span> + <span class="ow">onderwerp</span> **?** Het antwoord is het <span class="lv">lijdend voorwerp</span>.

## Voorbeelden
- \| <span class="ow">Stampertje</span> \| <span class="wg">pest</span> \| <span class="lv">Tak</span> \|.
- \| <span class="ow">Tak</span> \| <span class="wg">jaagt</span> \| <span class="lv">de konijnen</span> \| <span class="wg">op</span> \|.
- \| <span class="ow">Tak</span> \| <span class="wg">eet</span> \| <span class="lv">de mais</span> \|.
- \| <span class="ow">Mijn moeder</span> \| <span class="wg">voert</span> \| <span class="lv">Tak</span> \| elke ochtend \|.

---

# Meewerkend voorwerp (mv)
Het <span class="mv">meewerkend voorwerp</span> geeft aan voor wie iets bestemd is.

## Hoe vind ik het meewerkend voorwerp?
Stel de vraag **Aan wie +** <span class="wg">werkwoordelijk gezegde</span> + <span class="ow">onderwerp</span> + <span class="lv">lijdend voorwerp</span>**?** Het antwoord is het <span class="mv">meewerkend voorwerp</span>.

## Voorbeelden
- \| <span class="ow">Tak</span> \| <span class="wg">geeft</span> \| <span class="mv">de konijnen</span> \| <span class="lv">een preek</span> \|.
- \| <span class="ow">Stampertje</span> \| <span class="wg">geeft</span> \| <span class="mv">Tak</span> \| <span class="lv">een duw</span> \|.
- \| <span class="ow">Stampertje</span> \| <span class="wg">vertelt</span> \| <span class="mv">Tak</span> \| <span class="lv">een verhaal</span> \|.
- \| <span class="ow">Mijn moeder</span> \| <span class="wg">heeft</span> \| <span class="mv">Tak</span> \| <span class="lv">graan</span> \| <span class="wg">gegeven</span> \|.

---

# Bijwoordelijke bepaling (bwb)
Een <span class="bwb">bijwoordelijke bepaling</span> geeft een *plaats*, *tijd* of *reden* aan.

## Hoe vind ik bijwoordelijke bepaling?
Zoek het <span class="ow">onderwerp</span>, <span class="wg">werkwoordelijk gezegde</span>, <span class="lv">lijdend voorwerp</span> en <span class="mv">meewerkend voorwerp</span>. Zoek of er zinsdelen zijn die antwoord geven op vragen zoals **Waar?**, **Wanneer?** en **Hoe?**. Dit zijn (meestal) <span class="bwb">bijwoordelijke bepalingen</span>. De vraagwoorden zelf zijn ook <span class="bwb">bijwoordelijke bepalingen</span>.

## Voorbeelden
- \| <span class="ow">Tak</span> \| <span class="wg">zoekt</span> \| <span class="lv">eieren</span> \| <span class="bwb">in het kippenhok</span> \|.
- \| <span class="ow">Tak</span> \| <span class="wg">scharrelt</span> \| <span class="bwb">door de tuin</span> \|.
- \| <span class="ow">Tak</span> \| <span class="wg">legt</span> \| <span class="bwb">elke ochtend</span> \| <span class="lv">een ei</span> \|.
- \| <span class="ow">Mijn moeder</span> \| <span class="wg">geeft</span> \| <span class="mv">Tak</span> \| <span class="bwb">'s avonds</span> \| <span class="lv">graan</span> \|.
- \| <span class="ow">Tak</span> \| <span class="wg">verstopt zich</span> \| <span class="bwb">vanwege de regen</span> \|.
- \| <span class="ow">Tak</span> \| <span class="wg">piept</span> \| <span class="bwb">luidkeels</span> \| <span class="bwb">uit angst</span> \|.
- \| <span class="bwb">Waarom</span> \| <span class="wg">blokkeert</span> \| <span class="ow">Stampertje</span> \| <span class="lv">mijn pad</span> \|?
